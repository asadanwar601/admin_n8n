Standalone Admin Package (admin_n8n)

Embeddable Knowledge Base & Hybrid RAG Admin

100% isolated from customer chat. Embed this widget directly inside any existing website's Admin Portal to upload PDFs/Docs/CSVs or scrape Website URLs using your n8n Admin Cred.

1. Embed via Single Script Tag (Any Admin Portal)

<div id="admin-rag-portal"></div> <link rel="stylesheet" href="https://your-admin-widget.pages.dev/style.css" /> <script src="https://your-admin-widget.pages.dev/admin-widget.bundle.js" data-api-url="https://n8n-saas-host.onrender.com/v1/admin/rag" data-target="#admin-rag-portal" data-title="VELOUR Knowledge Base Admin" data-primary-color="#201c18" defer> </script>

2. Embed in React / Next.js Admin Dashboard

"use client"; import { useEffect } from "react"; import { createAdminRag } from "admin_n8n"; import "admin_n8n/style.css"; export default function KnowledgeBaseAdminTab() { useEffect(() => { const widget = createAdminRag({ apiUrl: "https://n8n-saas-host.onrender.com/v1/admin/rag", target: "#admin-rag-portal", mode: "inline", title: "VELOUR Knowledge Base Admin", primaryColor: "#201c18", }); return () => widget.destroy(); }, []); return <div id="admin-rag-portal" />; }
